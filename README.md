# Indian-Agriculture-Crop-Production-Analysis-(1990-2021)

## Overview

This project presents a visual analysis of India's agricultural cultivation and crop production from 1997–98 to 2020–21. The analysis explores production trends, cultivated area, crop performance, seasonal variations, and regional distribution across India.

The project uses Tableau to transform agricultural data into interactive visualizations and dashboards that help identify patterns and support data-driven decision-making.

### Problem Statement

The objective of this project is to analyze historical agricultural data from India to understand crop production trends, regional differences, cultivated area, yield, and seasonal patterns. The analysis aims to provide useful insights for farmers, government policy analysts, and agribusiness investors.
